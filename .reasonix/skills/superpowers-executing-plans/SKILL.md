# 执行计划

## 概述

加载计划，批判性审查，执行所有任务，完成时报告。

**开始时宣布：** "我正在使用 superpowers-executing-plans 技能实现此计划。"

**注意：** 如果 Reasonix Code 支持子代理，使用子代理可以获得更高质量。但在当前环境中，我们使用内联逐任务执行。

## 流程

### 步骤 1：加载并审查计划

1. 使用 `read_file` 读取计划文件
2. 批判性审查 — 识别关于计划的任何问题或疑虑
3. 如果有疑虑：在开始前向用户提出
4. 如果没有疑虑：创建 `todo_write` 并继续

### 步骤 2：执行任务

对于每个任务：
1. 标记为 `in_progress`
2. 按照计划中的每个步骤精确执行
3. 运行指定的验证命令
4. 标记为 `completed`
5. **不要**在任务之间暂停询问用户——连续执行直到所有任务完成或遇到阻塞

### 步骤 3：完成开发

所有任务完成并验证后：
- 运行完整测试套件：`.venv\Scripts\python.exe -m pytest`
- 使用 `superpowers-finishing-branch` 技能收尾

## 何时停止并求助

**遇到以下情况立即停止执行：**
- 遇到阻塞（缺少依赖、测试失败、指令不清晰）
- 计划有关键缺口导致无法开始
- 你不理解某个指令
- 验证反复失败

**请求澄清而不是猜测。**

## 红旗信号

**永远不要：**
- 未经用户明确同意在主分支上开始实现
- 因为"简单"而跳过验证
- 忽略计划中的子技能引用（如 TDD）
- 强制通过阻塞——停下来问

**始终：**
- 先批判性审查计划
- 精确遵循计划步骤
- 不跳过验证
- 被阻塞时停下来，不要猜测
